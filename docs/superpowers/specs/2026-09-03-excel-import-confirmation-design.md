# Excel 智能导入与确认设计

## 目标与边界

在现有“新建物业测算项目”页补齐可见的 Excel 智能导入入口。用户上传格式不一的 `.xlsx` 后，系统调用现有 `/api/excel/recognize` 接口识别字段，用户确认识别结果，再回到现有五步表单补充或修改，最后沿用原“开始测算”流程。本轮不新增页面路由、不修改测算模型、不自动开始测算，也不增加 AI 项目洞察。

## 交互方案

页面标题下方增加一块紧凑的“Excel 智能导入”操作区，支持点击或拖入文件，手动录入仍保持可用。选择文件后显示明确的等待状态：“正在读取并识别项目数据，通常需要约 1 分钟”，避免用虚假百分比模拟进度。

识别完成后打开结果确认框，展示文件名、已识别项数、待补充项数，以及按“项目、园林、楼栋、地库、参数”分组的字段和值。低置信字段标记“请核对”，缺失字段标记“待补充”；界面展示业务字段和值，不展示模型提示词、内部字段名或内部实现说明。用户选择“采用识别结果”后才写入现有表单，随后仍需逐步核对并点击“开始测算”。取消则不改变原表单。

## 数据与状态

前端新增独立的识别接口客户端，以二进制方式上传 `.xlsx`，文件名放在请求头中。状态只有 `idle / recognizing / review / error / applied`。回填时以识别结果为准，包括明确的空值，防止示例项目数据残留；城市成本档位使用后端已派生结果，未知城市保持未选择。识别结果只驻留当前页面状态，不写入项目中心，只有完成测算后才按原逻辑保存项目。

## 异常处理

只接受 `.xlsx`，前端限制 10MB。文件不合规时立即提示；接口失败时保留原表单并允许重新上传；存在缺失字段时仍允许采用结果，但自动定位到第一个缺失字段所属步骤，并提示用户补齐。表单原有校验是进入测算前的最终防线。

## 验收

自动化测试覆盖：入口可见、上传期间状态、识别结果在确认前不污染表单、确认后完整回填、缺失字段保持为空、取消与失败保留原数据。实际页面验收使用 `/project/new`，核对默认状态、真实样本识别、结果确认框、回填表单和错误提示；本轮不验收 PPT、标书及其他页面。
