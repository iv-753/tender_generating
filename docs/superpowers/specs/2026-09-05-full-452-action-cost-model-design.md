# 452 项完整物业成本模型设计

## 1. 目标与范围

本次升级将现有 122 项、4 类服务测算扩展为完整的 452 项、7 类服务测算，并纳入独立的管理人员成本，使年度总成本和服务成本单价不再因缺少工程、消杀及管理模块而系统性偏低。

系统继续脱离 Excel 在线计算。原 Excel 仅作为内部公式、默认参数和回归结果的迁移依据，不进入部署包，也不提供给客户。

本次不处理旧项目迁移或删除；用户已自行清理本地旧项目。公司资料、模板及现有文件生成能力保持不变。

## 2. 完整动作与成本口径

标准动作库固定包含 452 项：

| 服务类别 | 动作数 |
| --- | ---: |
| 客户服务 | 17 |
| 清洁服务 | 48 |
| 绿化养护 | 51 |
| 客助服务 | 6 |
| 四害消杀 | 7 |
| 工程委外 | 95 |
| 工程常规 | 228 |
| 合计 | 452 |

管理模块的项目经理、管家主任、工程主任和客助主任为 4 个管理岗位，单独计入管理人员成本，不计入 452 项服务动作。

每次测算都生成完整的 452 项动作。某项设施的默认数量或客户调整值为 0 时，相关动作仍保留在结果中，但数量、工时和成本为 0，并标记为“当前未配置”。用户可以筛选隐藏零值动作，但页面总动作口径始终为 452 项。

## 3. 参数结构

### 3.1 基础参数

现有项目概况、园林概况、楼栋概况、地库概况、服务等级和城市成本档位继续作为基础参数，当前录入流程和必填规则不变。

### 3.2 高级参数

新增约 65—80 项高级参数，最终数量以参数字典去重结果为准。高级参数按业务对象分为四组：

1. 地库及设备房：防火卷帘、监控、排污设备、配电房、泵房、风机房等。
2. 楼栋及公区：电梯、管井、避难层、外立面、商业公区、屋面等。
3. 园区设施：闸机、水景、泳池、运动场、围墙、管网、井点等。
4. 人员及成本：管理岗位、客助岗位、消杀单价、工程委外价格等。

所有高级参数均由系统预先给出默认值，不增加新的必填项。客户可以完全不打开高级参数，也可以展开后修改任意一项，并可按单项或整组恢复系统默认值。

每项高级参数必须保存以下信息：稳定编号、名称、分组、单位、默认值、当前值、值来源、所影响动作及规则版本。值来源统一分为：

- 直接推算：由现有面积、楼栋、户数、地库等基础参数直接计算。
- 规则估算：依据项目规模和已知设施数量按比例推算。
- 模板默认：使用原 Excel 示例模型中的默认设备或价格参数。
- 手动调整：客户覆盖系统生成值。

系统不得把工程表中重复出现的 323 个动作数量单元格直接做成 323 个输入项。同一设施的巡查、检测、保养等动作必须共用同一个高级参数。

## 4. 默认参数生成

默认参数生成器按固定优先级工作：

1. 能由基础参数确定的值直接计算。
2. 无法直接确定但可按项目规模推算的值使用规则估算。
3. 无可靠推算关系的值使用 Excel 模板默认值。

默认参数不是结果校准器。系统不得为了让最终单价达到指定数字而反向修改参数、成本或人员数量。

原 Excel 示例项目载入完整默认参数后，应自然得到与 Excel 基本相同的四档结果：A 档约 3.156 元、B 档约 2.590 元、C 档约 2.262 元、D 档约 1.947 元每平方米每月。差异仅允许来自页面显示精度或明确保留的取整规则。

客户改变基础参数后，依赖该参数的默认高级参数自动重新生成；已经手动调整的高级参数不被自动覆盖，并明确标记为“手动调整”。客户选择恢复默认后，才重新采用最新推算值。

## 5. 计算结构

完整计算链路为：

`基础项目参数 → 默认高级参数 → 客户高级参数覆盖 → 452 项动作规则 → 7 类成本与人员汇总 → 管理人员成本 → 年度总成本 → 服务成本单价`

服务成本单价继续采用：

`年度总成本 ÷ 住宅收费面积 ÷ 12`

452 项的动作名称、服务属性、等级频次、数量依据、单位工时、委外价格及特殊规则均从原 Excel 迁移到代码和规则数据中。人员向上取整、城市成本档位、服务等级、管理及客助附加比例等继续沿用原 Excel 口径。

页面继续区分“年工作量成本”和“项目年度用工预算”：动作工时变化会立即改变工作量成本；项目预算按分类汇总后的完整岗位人数计算，因此只有越过人员取整临界点时才变化。四害消杀和工程委外按各自的作业或委外成本口径汇总，不强行套用人工岗位公式。

## 6. 页面设计

现有五步基础录入保持不变。在开始测算区域增加“高级参数（可选，系统已估算）”入口。高级参数页面按四组折叠展示，并显示每组参数数量、手动调整数量和默认值来源。

结果页顶部展示：452 项服务动作、7 类服务、配置人数、管理人员成本、年度总成本和服务成本单价。明细区按 7 个类别切换，每页显示约 15 项，支持搜索及以下筛选：

- 只看有成本的动作；
- 显示或隐藏零值动作；
- 只看已调整动作；
- 只看已停用或自定义动作。

现有年频次、年工时、配置人数、停用、恢复和新增动作能力扩展到完整动作库。452 项数据可以一次加载，但页面不得一次渲染全部行；继续使用分类、分页或虚拟滚动控制展示量。

页面不向普通客户展示 452×全部变量的稠密矩阵。运行时采用稀疏规则结构，每个动作只保存实际使用的参数。面向客户的高级参数按业务对象编辑；参数矩阵留作后续管理功能，不属于本次升级。

## 7. 数据与版本

完整模型使用新的计算结果版本，并记录动作规则版本、默认参数规则版本及本次测算采用的高级参数快照，确保同一项目重新打开后结果可复现。

本次不建设数据库，继续使用现有本地项目存储。旧项目不增加迁移、兼容或清理逻辑；公司资料和模板的数据结构不变。

PPT和投标标书继续消费统一的最终计算结果。用户保存高级参数或动作调整后，页面、项目概览、PPT和标书必须使用同一份结果，避免金额和动作口径不一致。

## 8. 异常处理

- 所有数量、频次、工时、人数和金额必须为有限非负数。
- 高级参数缺少默认规则或动作引用不存在时，返回明确的系统配置错误，不使用 0 静默掩盖。
- 住宅收费面积为 0 时，服务成本单价显示“—”。
- 手动值与基础参数明显冲突时提示客户复核，但不擅自修改客户输入。
- 任一动作为 0 值时仍保留稳定编号和完整结果结构。

## 9. 验收标准

1. 任意有效项目均固定生成 452 项动作，分类数量必须为 17、48、51、6、7、95、228。
2. 原 Excel 示例项目在未修改高级参数时，四档服务成本单价与 Excel 的差异不超过 0.01 元/平方米·月。
3. 年度总成本完整包含 7 类服务成本和管理人员成本，不再沿用 122 项局部成本口径。
4. 每个高级参数都有默认值和来源；修改参数只影响参数字典中明确关联的动作及其汇总结果。
5. 数量为 0 的设施仍生成对应动作，动作成本为 0；恢复默认后结果能够回到初始测算值。
6. 452 项结果的查看、搜索、筛选、分页和动作调整可正常使用，页面不一次渲染全部动作。
7. 页面、项目概览、PPT和标书中的动作数量及成本金额一致。
8. 线上运行、部署包和浏览器网络请求均不包含原 Excel 文件。

## 10. 实施顺序

后续实施按以下顺序推进：先建立高级参数字典及动作关联，再迁移剩余 330 项规则和完整成本汇总，随后接入高级参数页面与 7 类结果页，最后完成四档回归、页面验收及导出文件一致性验证。
