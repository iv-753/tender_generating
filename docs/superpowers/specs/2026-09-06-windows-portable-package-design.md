# Windows 免安装本地包设计

## 目标

将当前 `main` 版本制作成可直接发送给非技术人员的 Windows 压缩包。用户解压后双击“启动物业方案工作台”即可自动启动本地服务并打开浏览器，不需要安装 Node.js、npm、pnpm，也不需要接触命令行。

本地包作为线上站点的业务备份：线上站点无法访问或演示现场网络不稳定时，项目录入、成本测算、服务动作调整、PPT 生成和投标标书生成仍可在本机完成。

## 本轮边界

- 不修改现有成本算法、动作数据、模板内容和线上站点业务逻辑。
- 不制作安装程序、Electron 桌面应用或单文件 EXE。
- 不在压缩包中放置千问或其他第三方 API 密钥。
- 不承诺复杂 Excel 的 AI 识别完全离线；断网时由本地规则识别和人工校正兜底。
- 不增加数据库、账号系统、自动更新或云端数据同步。

## 交付形态

压缩包解压后包含以下用户可见内容：

```text
物业方案工作台-本地版/
├─ 启动物业方案工作台.cmd
├─ 关闭物业方案工作台.cmd
├─ 使用说明.txt
├─ 生成文件/
└─ app/                 # 程序、便携运行环境、模板及依赖，普通用户无需操作
```

运行环境和生产依赖全部随包提供，打包过程及缓存只使用 Z 盘。用户电脑无需管理员权限，程序不向系统目录安装内容。

## 启动与关闭

启动程序执行以下流程：

1. 检查压缩包是否完整，并识别是否已有本地实例运行。
2. 优先使用 `127.0.0.1:4173`；端口被占用时自动选择其他空闲端口。
3. 使用包内便携 Node.js 在后台启动服务，等待健康检查成功。
4. 自动用默认浏览器打开本地首页。
5. 重复双击启动时不创建第二个服务，只打开已运行页面。

关闭程序只停止本地包记录的进程，不影响电脑上的其他程序。异常退出后残留的无效进程记录会在下次启动时自动清理。

## 功能分层与双保险

### 完全本地运行

- 页面和项目数据操作。
- 物业成本测算及服务动作调整。
- PPT 和投标标书生成。
- 模板、算法和默认参数读取。
- 常见 Excel 字段、表头和同义词的规则识别。

生成的 PPT、Word 和运行日志统一写入压缩包内的“生成文件”目录，避免用户寻找系统临时目录。

### 联网增强

复杂或结构混乱的 Excel 在本地规则无法充分识别时，由本地服务把文件转发到：

`https://www.zhiyingtupu.website/api/excel/recognize`

浏览器始终只访问本机服务，由本机服务负责转发，因此无需处理浏览器跨域问题，也不会在前端暴露密钥。

### 网络或线上接口不可用

- 本地规则仍先完成能够确认的字段识别。
- 页面明确提示“智能识别暂时不可用”，并展示已识别结果。
- 用户可在确认页补充或修改字段，然后继续测算。
- 不因 AI 接口失败阻断测算、PPT或标书生成。

因此，本地包与线上网站不是完全相同的单点依赖：核心业务独立运行，只有复杂 Excel 的 AI 增强共用线上能力。

## 安全要求

- 压缩包不得包含 API 密钥、部署环境变量文件或历史生成文件。
- 远程识别地址固定为 HTTPS 官方域名，不接受页面传入任意转发地址。
- 本地服务仅监听 `127.0.0.1`，不向局域网开放。
- 上传文件沿用现有类型和大小限制，临时文件处理完及时删除。
- 启停程序使用包内进程标识，只能关闭本包启动的进程。

## 异常提示

- 文件缺失：提示重新解压完整压缩包。
- 端口冲突：自动切换端口，无需用户处理。
- 服务启动失败：显示简短原因，并指向包内日志。
- 无网络或 AI 超时：提示改用本地规则结果并人工确认。
- 模板缺失或生成失败：保留现有项目数据，提示缺失文件名称，不要求重新录入。

## 验收标准

1. 在未安装 Node.js、npm、pnpm 的 Windows 电脑上，解压后双击即可打开网站。
2. 断网状态下能够新建项目、完成测算、调整服务动作，并生成 PPT 和投标标书。
3. 联网状态下，复杂 Excel 可以调用线上 AI 增强识别；接口失败时能够回退到本地规则和人工确认。
4. 生成文件名称正常，保存到“生成文件”目录，重启后仍可访问。
5. 重复启动不产生多个服务，关闭程序不会误停其他进程。
6. 压缩包中扫描不到 API 密钥、用户项目数据和历史生成结果。

## 最小验证范围

- 一台无开发环境的 Windows 电脑进行解压、启动、关闭验证。
- 各执行一次本地测算、PPT生成、标书生成。
- 使用同一份 Excel 分别验证联网增强和断网回退。
- 模拟端口占用、重复启动和线上识别超时。
- 对压缩包内容进行密钥及敏感文件检查。
